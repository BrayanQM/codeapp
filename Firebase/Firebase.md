# clase con el ingeniero de moviles

Objetivo
Desarrollar una API REST que permita a una aplicación móvil consultar y modificar información mediante HTTP y JSON.
 
Aplicación propuesta
               "API de gestión de productos"
 
La API debe permitir:
• Registrar producto 
• Consultar productos 
• Consultar un producto 
• Modificar producto 
• Eliminar producto 
• Devolver respuestas JSON 
• Probar endpoints mediante Postman/Thunder Client
 
Las 4 alternativas
El estudiante puede desarrollar el backend utilizando:
Opción         Tecnología
  A            Node.js + Express
  B            Python + Flask
  C            Laravel + PHP
  D         Firebase Realtime Database
 
Pero todos deben cumplir la misma especificación.
 
Endpoints mínimos
GET     /api/productos                           (Listado de Productos)
GET     /api/productos/{id}                   (Mostrar un único elemento de una búsqueda)
POST    /api/productos                         (Guardar o salvar los datos de un producto)
PUT     /api/productos/{id}                  (Actualización de los datos de un producto)
DELETE  /api/productos/{id}               (Eliminación de los datos de un producto)
Aplicación móvil
Posteriormente, Android Studio/Kotlin consume la API.
Por ejemplo:
Android
   ↓
HTTP/REST
   ↓
API
   ↓
Base de datos
 
Demostración
El estudiante de manera individual debe demostrar y presentar:
• API funcionando. 
• Pruebas en Postman. 
• Aplicación Android. 
• Operaciones CRUD desde la aplicación. 
• Informe de la Actividad
 
Producto final: 
API + aplicación móvil cliente.
